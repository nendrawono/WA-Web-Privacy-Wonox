# 🛡️ WA Web Privacy & Quick Chat Extension

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-Proprietary-red)
![WhatsApp Web](https://img.shields.io/badge/WhatsApp_Web-Supported-25D366?logo=whatsapp)

Ekstensi Google Chrome ringan untuk meningkatkan **privasi visual** dan **efisiensi berkirim pesan** saat menggunakan WhatsApp Web. Sangat cocok bagi profesional, pekerja *remote*, maupun pengajar yang sering melakukan **Share Screen / Live Presentation**.

---

## ✨ Fitur Utama

* **🛡️ Mode Privasi Automatic (Hover to Reveal):** Menyamarkan isi chat, nama kontak, dan foto profil secara otomatis. Teks/gambar hanya akan terlihat jelas saat kursor mouse diarahkan ke atasnya (*hover*).
* **📱 Kirim Pesan Tanpa Simpan Nomor:** Fitur *Quick Chat* langsung dari WhatsApp Web tanpa perlu mengotori buku telepon smartphone Anda.
* **⚡ Instant Toggle Shortcut:** Matikan/hidupkan efek blur secara cepat hanya dengan menekan tombol keyboard **`Alt + Shift + P`**.
* **🌙 Auto Dark Mode Support:** Tampilan widget menyesuaikan tema sistem/laptop Anda secara otomatis (Light & Dark Mode).
* **🌐 Support Multi-Bahasa:** Teks petunjuk otomatis menyesuaikan bahasa default browser pengguna (Bahasa Indonesia & Bahasa Inggris).

## 📥 Cara Download & Instalasi di Google Chrome

Karena ekstensi ini didistribusikan secara independen melalui GitHub, ikuti langkah mudah berikut untuk memasangnya di browser Anda:

### Step 1: Download File Kode
1. Klik tombol hijau **`<> Code`** di bagian atas halaman GitHub ini.
2. Pilih **`Download ZIP`**.
3. *Extract* (ekstrak) file `.zip` tersebut ke dalam folder khusus di komputer/laptop Anda (misalnya: `C:\Users\Nama\Documents\wa-privacy-extension`).

### Step 2: Pasang di Google Chrome
1. Buka browser **Google Chrome**.
2. Ketik `chrome://extensions/` pada address bar lalu tekan **Enter**.
3. Di pojok kanan atas halaman, aktifkan sakelar **`Developer mode`** (Mode pengembang).
4. Klik tombol **`Load unpacked`** (Muat yang tidak dikemas) di pojok kiri atas.
5. Pilih **folder hasil ekstrak** file ekstensi tadi.
6. Selesai! Buka atau *refresh* halaman [web.whatsapp.com](https://web.whatsapp.com) untuk mulai menggunakan.

## 🎮 Cara Penggunaan

* **Privasi / Blur:** Secara otomatis aktif saat Anda membuka WhatsApp Web. Arahkan mouse ke percakapan untuk membaca pesan.
* **Shortcut ON/OFF:** Tekan **`Alt + Shift + P`** untuk mematikan fitur blur saat tidak digunakan, atau hidupkan kembali saat ingin *meeting / share screen*.
* **Kirim Pesan Cepat:** Ketik nomor HP target (misal: `08123456789`) pada kolom *Quick Chat* di atas daftar obrolan, lalu tekan **Enter** atau klik tombol **Chat**.
